# Full Production Studio — skills index

This repo is a library of Agent Skills for video & content production.
Each skill lives in `skills/<name>/SKILL.md` (YAML frontmatter + instructions).

**For any AI agent reading this file:** when a task matches a skill below, open its SKILL.md and follow it. Load files referenced inside a skill folder only when the skill asks for them.

**Not sure which skill fits, or making a whole video?** Start with `skills/studio-director/SKILL.md`: it routes each production stage to the right skill. For Arabic-language content, prefer the `arabic-*` skills.
